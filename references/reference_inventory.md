## Rules

1. The fixed collection remains exactly 15 papers.
2. For pending items, verify full title, authors, journal metadata and DOI from the uploaded PDF before treating the citation as final.
3. Preserve all selected works. If a PDF is incorrect or incomplete, flag it for user resolution; do not silently substitute another paper.
4. Use the uploaded PDFs as the evidence base. Outside information may be used only for explicit verification and must be distinguished from the paper's own claims.
5. Distinguish measured uptake, derived uptake, fitted maximum capacity and removal percentage.
