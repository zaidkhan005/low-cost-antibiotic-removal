# PowerPoint

The editable PowerPoint will be created only after the slide-by-slide content has been reviewed.

Final quality checks:
- 16:9 widescreen layout;
- readable academic typography and restrained colour palette;
- consistent in-slide citations;
- human-readable equations and correctly rendered subscripts/superscripts;
- diagrams are complete and scientifically accurate;
- no clipped or overlapping text;
- final reference slide contains the complete fixed 15-paper bibliography;
- render every slide and inspect the full deck before delivery.
