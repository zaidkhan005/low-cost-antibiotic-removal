# Presentation Content

The approved structure is in `docs/PROJECT_PLAN.md`.

No slide copy should be treated as final until:
1. the source PDFs are audited;
2. the evidence matrix is populated;
3. equations, values and citations are checked;
4. limitations and context are recorded.

The draft should contain slide titles, key messages, concise body copy, diagram/table specifications, speaker notes and in-slide citations.
