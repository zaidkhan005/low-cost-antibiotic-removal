# Diagrams

This directory contains figure assets and source/adaptation records for the review presentation.

## Source figures

See [Source Figure Register](source-figures/INDEX.md) for the figures supplied from Ajala et al. (2023), Teo et al. (2022), and Perelomov et al. (2025), including original captions, intended presentation slides, DOIs, attribution, and scientific-use cautions.

Prepared figure files are organised by paper under `source-figures/<paper-slug>/`:
- `ajala-2023/`
- `teo-2022/`
- `perelomov-2025/`

Each figure record should state:
- purpose and slide;
- source paper, exact figure number, and caption;
- labels and scientific meaning;
- attribution and licence / permission requirements.

Prefer original explanatory schematics when they improve understanding, but preserve supplied source figures when they are useful evidence or authoritative illustrations. Do not reconstruct a published diagram in a way that changes its scientific meaning.

**Repository status:** The source-figure register is committed. Prepared binary PNG assets are supplied in the companion ZIP bundle and should be added to the local repository from that bundle; do not treat those binary paths as committed until verified in the Git tree.
