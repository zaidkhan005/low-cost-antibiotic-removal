# Diagrams

This directory contains figure assets and source/adaptation records for the review presentation.

## Source figures

See [Source Figure Register](source-figures/INDEX.md) for the figures supplied from Ajala et al. (2023) and Teo et al. (2022), their original captions, intended presentation slides, DOIs, attribution, and reuse notes.

Store each figure alongside the register under `source-figures/<paper-slug>/`. Each figure record should state:
- purpose and slide;
- whether it is original or adapted;
- source paper, exact figure number, and caption;
- labels and scientific meaning;
- attribution and licence / permission requirements.

Prefer original explanatory schematics when they improve understanding, but preserve supplied source figures when they are useful evidence or authoritative illustrations. Do not reconstruct a published diagram in a way that changes its scientific meaning.

**Repository status:** The register is committed. The binary image files themselves must be verified in the Git tree before they are treated as saved repository assets.
