# Evidence Matrix

The evidence matrix will link slide claims to the fixed 15 references. Each evidence record should include:

- Claim or concept;
- supporting REF-ID(s);
- exact page, table, figure or equation;
- study type (review, experimental study, modelling);
- antibiotic and adsorbent where relevant;
- experimental conditions;
- whether the result is observed, derived, or model-fitted;
- qualification/limitation;
- intended slide(s).

No quantitative result should enter the slide deck without traceable source location and units.
